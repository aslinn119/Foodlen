## 阅读与运行边界

这是“集中查看版”，并非已经联调验收的独立运行版。各模块保留原有内部目录、说明、配置与代码；部分代码仍使用原路径或依赖外部权重，不能承诺直接从main运行。运行前先查模块README及外置清单，后续再统一路径和依赖。

文件是整理时的复制快照，不会随原目录自动更新。以后提交成果优先放入对应模块，并同步更新结果入口与进度；更新规则见[整理与维护规则](docs/整理与维护规则.md)。

## 数据文件范围

仓库沿用模块忽略规则：创新一原始验证图片不随Git提交，需从原始数据集取得；图表、样例和保存预测按实际跟踪清单收录。报告中“包内附图/权重”的描述属于原始完整交付包，不代表GitHub副本包含这些文件。当前仓库文件校验见assets/github_manifest.json，未上传文件说明见assets/Git忽略文件.json。
