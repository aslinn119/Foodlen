# 压缩包说明

源码与结果包：包含全部 Python 源码、requirements.txt、运行说明、实验报告、候选描述、CLIP 分数、SCST 日志、指标、样本ID和6张图的核查记录。

含RL断点包：在源码与结果包基础上增加 results/rl_last.pt（第33步模型、优化器及随机状态）。

两个包均不包含完整数据集、原始 CE 起点权重、ImageNet ViT 预训练权重和 CLIP 下载缓存，也不包含 Python 虚拟环境。原始权重路径与哈希见 results/manifest.json。迁移机器时需自行提供这些依赖，不能仅解压就视为可独立重新训练。

在解压后的 V4_experiments 上一级目录运行 README 中命令。其他机器可先创建 Python 3.11 虚拟环境，pip install -r V4_experiments/requirements.txt，然后用该环境的 python 替换 README 中本机 .venv-task2-check/Scripts/python.exe。CLIP 首次下载需联网并移除 HF_HUB_OFFLINE 设置；已有权重可用 --clip-model 指向本地模型目录。V4 必须使用配套 ImageNet ViT-B/32 编码器权重；仅 trainable_state 不包含该冻结骨干。

原模型未被覆盖，检查点仍为本机原路径。食材核查只有6张，不能把剩余空白标注当作已完成。
