# 单图营养预测区间优化 · 开发补充

使用 MetaFood3D 原训练 200 个和验证 50 个对象。按来源目录中的食物类别分五折，类别名只用于划分。每轮三折拟合岭回归头，一折计算 90% 校准分位数，一折评估；每个对象恰好留出一次。两个区间方法共用同一轮的点预测。整体特征提取器和方法设计已有开发历史。

固定半径取各字段绝对误差的校准分位数。候选方法用 s = sqrt(0.25 + 该字段点预测 / 拟合集该字段均值) 对绝对误差缩放，再乘回当前图片的 s。所有下界截到零。区间评分将宽度加上区间外误差的 20 倍，再除以该折训练字段标准差，越低越好。

|脂肪 g|35.21|27.71|95.2%|92.4%|5.376|5.249|
|碳水 g|54.94|53.12|90.8%|90.0%|3.626|3.516|

热量区间平均缩窄 73.33 kcal，少覆盖 1 个对象。脂肪少覆盖 7 个对象。蛋白质多覆盖 2 个对象，仍有 28/250 个对象落在区间外。此结果支持进一步独立验证。正式展示仍使用原已校准接口。本轮没有使用预留的 150 个校准对象或此前评估的 95 个测试对象，也未用正式 OmniFood8K 测试集选参数。

有原 MetaFood3D 训练、验证图像的工程可从根目录运行 python -m challenge_external.portion_interval_development。heldout.json 保存逐对象真值及两种区间，可复算本表。
