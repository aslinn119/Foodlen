## 六项交付

| 分工 | 可核对的证据 |
|---|---|
| 1．课程要求 | 课件第 59 页允许使用任务二数据，也允许加入 OmniFood8K 等外部数据。测试时仅输入一张普通食物 RGB 图，自动预测整道菜的总重量、热量、蛋白质、脂肪、碳水。测试前冻结系统，禁止测试泄漏、答案检索、人工修正、样本级硬编码和测试集调参。[要求核对与实验协议](challenge_audit/omnifood/任务要求核对与实验协议.md) |
| 2．同划分基线 | 训练集均值、ResNet18、CLIP＋LoRA 复用任务二的统计量或权重，在相同的 2,368 个 OmniFood8K 场景比较。每个场景固定一张 camera_4 图片，指标按字段列出，含 MSE。[完整对照表](challenge_external/results/metrics.csv) |
| 3．独立校准集 | 5,668 个外部场景用于校准，没有参与已记录的模型训练和选型，与最终评估场景 ID 互斥。采集批次关系未知。[校准清单](challenge_audit/omnifood/calibration_manifest.jsonl) · [评估清单](challenge_audit/omnifood/evaluation_manifest.jsonl) |
| 4．Split Conformal | 每模型、每字段独立校准，以 90% 为目标。主实验阈值取 5,668 个校准绝对残差中第 5,103 小的值，先固定阈值再评估。[校准参数与版本](challenge_external/results/calibration.json) |
| 5．覆盖、宽度与失败 | 主报告按五个字段给出实测覆盖率、区间宽度、误差和失败例。全部 3,035 条“模型 × 场景”欠覆盖记录均可追溯。[全部欠覆盖记录](challenge_external/results/undercoverage_cases.jsonl) |
| 6．展示接口 | 传入一张图，可返回五项点预测、上下界、单位、模型版本、校准版本与目标覆盖率。主实验调用 `predict_intervals(image_path, model_id="clip")`。[接口实现](challenge_external/runtime.py) · [实际输出示例](challenge_external/results/interface_example.json) |

主实验中，CLIP＋LoRA 的总重量覆盖率为 **92.74%**，脂肪为 **73.10%**。90% 指各字段的目标覆盖率，实测结果因字段和数据域而异。

## 两个补充实验

- **NutritionVerse-Real 餐盘。** 225 道菜按训练、验证、校准、测试分为 68 / 30 / 60 / 67。与原 CLIP＋LoRA 相比，适配模型的热量 MAE 从 636.93 降至 431.97 kcal，热量区间覆盖 62/67，平均宽 1,928.61 kcal；碳水覆盖 56/67。[餐盘报告与案例](challenge_external/nutritionverse_extension/餐盘优化实验报告.md)
- **MetaFood3D 单对象。** 495 个对象划分为 200 / 50 / 150 / 95。验证集选出的岭回归头在留出测试的五项 MAE 均低于原 CLIP。热量 MAE 从 170.30 降至 129.00 kcal，区间覆盖 88/95；总重量和蛋白质各覆盖 83/95。[字段结果](challenge_external/metafood_extension/metrics.json) · [欠覆盖案例](challenge_external/metafood_extension/undercoverage.json)
- 两套补充数据随附逐样本图片、划分和来源。开发折上的后续模型对照另行记录。[数据与许可](challenge_external/data_supplement_v1/补充数据验收与使用说明.md) · [开发实验结论](challenge_external/final_development_review/最终对照报告.md)

## 如何复核

在解压后的根目录，使用已安装依赖的 Python 依次运行。三条命令分别复算主实验、餐盘和单对象实验，并实际运行单图预测。

```powershell
python -m challenge_external.verify_delivery
python -m challenge_external.verify_nutritionverse
python -m challenge_external.verify_metafood
```

上述复核使用包内的逐样本记录、权重和图片。若要从全部 8,036 张原始场景图重新运行 OmniFood8K 推理，另需将约 2.73 GB 的 `0-OminiFood8k.zip` 放在独立实验副本的根目录。根目录的 `predict.py` 是当时登记的任务二源码，供冻结身份核验。
