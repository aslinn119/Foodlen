## 一、Task 2 是什么

输入一张菜品照片（`dish_*.png`），输出一个营养 JSON，例如：

```json
{
  "items": [{"name": "bacon", "weight_g": 23.0}],
  "total_weight_g": 23.0,
  "total_calories_kcal": 124.4,
  "protein_g": 8.5,
  "fat_g": 9.7,
  "carbohydrate_g": 0.3
}
```

### 阶段 2：基线与主模型（10/13 – 10/18）

**任务 2.1 — 均值基线（半天就能完成，但必须做）**

- 用 train 集四个营养值的均值直接预测所有 val/test 样本
- 这是报告的「下限对照」，没有它实验部分不完整

**任务 2.2 — 主模型：ResNet18 多输出回归**

- 图像 → ResNet18（ImageNet 预训练）→ 换掉最后的 fc → 同时回归 4 个值（calories/protein/fat/carb）
- 参考 v1_cnn_gru 里 data.py 的写法和 train.py 的训练循环结构，保持代码风格一致
- 损失：对 4 个目标做归一化后求 MSE（先记录 train 集各目标的标准差用于归一化）
- 数据增强：随机裁剪/翻转即可，不要太花哨

**任务 2.3 — 评估指标**

- MAE 和 RMSE（每个营养值分别算），再算一个相对误差（MAE / 该目标均值）
- 在 val 上选模型，test 只跑一次
- 结果对比表：均值基线 vs ResNet18 回归

**验收标准（10/18 检查点 CP2）**：
1. test 集上 4 个营养值的 MAE/RMSE 表
2. 至少一张「预测 vs 真值」散点图（卡路里那张必画）
3. 训练 loss 曲线
4. 结论一句话：比基线好多少（预期应显著好于均值基线）
