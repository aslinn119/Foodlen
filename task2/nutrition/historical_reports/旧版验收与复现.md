# FoodLens Task 2 验收与复现

可选 B 超限筛选使用 `predict_nutrition(image_path, "b", b_rank_overflow=True)`。沿用检查点阈值 0.625，仅在超过 16 项时按置信度保留前 16 项。验证集 micro-F1 从 0.4101 升至 0.4150，空列表均为 8/414。该模式为验证集补充实验，正式配置仍使用原筛选规则。

可选 B 食材筛选使用 `predict_nutrition(image_path, "b", b_calibrated=True)`。五折验证均从其余四折选出 0.75 阈值与按置信度截取最多 16 项的策略。合并留出预测后，micro-F1 从 0.4101 升至 0.4262，macro-F1 从 0.4308 升至 0.4519，micro-recall 从 0.5622 降至 0.4811。适合更重视减少误报的场景。正式默认结果沿用检查点阈值。用 `python eval_b_ingredient_selection.py` 在具有教学云验证图片时复算，产出 `final_results/b_ingredient_selection_validation.json`。

B-gen 可选回退使用 `predict_nutrition(image_path, "bgen", bgen_fallback_to_b=True)`。仅在完全解析失败时用同图模型 B 的结构化输出。verbose 接口保留原文和解析状态，另在生成信息标记实际回退模型。414 张验证图中触发 3 次，整集平均 MAE 从 33.69 降至 33.08。样本很少，本结果作为补充实验。运行 `python eval_bgen_fallback.py` 可复算。

可选 B-gen 去重使用 `predict_nutrition(image_path, "bgen", bgen_deduplicate=True)`。同名食材保留最大预测分量。414 张验证图上，按同一菜品内预测与标注的食材并集计算，缺项按 0 克计，分项重量 MAE 从 49.20 降至 42.16 克。分项合计距预测总重 5 克内的比例从 14.36% 降至 13.14%（仅计非空食材样本）。正式评分使用默认接口。通过 `python postprocess_bgen.py --validation-only` 复算本实验，结果见 `final_results/bgen_item_weight_validation.json`。

本文件与 final_results/ 记录当前版本。附带 Word 文档是历史稿，数值和模型定位以本说明为准。

补充实验融合 B 与 B-gen 的五项数值输出。414 张验证图按菜品划分五折，每折用其余四折选融合权重。合并留出结果后，平均 MAE 从 B 的 30.56 降至 30.05，平均 MSE 从 4297.19 降至 4154.35，五折有一折的 MAE 上升。融合要调用两套预测，正式接口继续采用独立模型。运行 `python eval_numeric_blend.py` 可复算，完整结果见 `final_results/numeric_blend_validation.json`。

本轮从完整原图重新运行 A/B 的验证集和测试集推理。对照包内记录，文本及食材指标差异均在 0.0001 内，四组平均 MAE 一致。保存预测复算覆盖三个模型的全部文本、食材和各字段数值指标。
